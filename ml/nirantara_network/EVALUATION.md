# Nirantara model evaluation

These results describe the fixed model supplied for deployment. They are not
new training or quantization results generated by this publication branch.

| Measurement | Result |
| --- | ---: |
| FP32 test accuracy | approximately 0.977 / 97.70% |
| INT8 test accuracy | 0.976417 / 97.6417% |
| Accuracy drop | 0.000583 |
| Input | INT8 `[1, 22]` |
| Output | INT8 `[1, 3]` |

The INT8 model was inspected as four `FULLY_CONNECTED` operators followed by
`SOFTMAX`. The model hash is recorded in `README.md` and in the firmware model
inspection document.

## Deterministic test vector

The firmware and host test use the same quantized vector:

```text
[59, 70, 69, 71, 68, 73, 70, 70, 74, 88, 71,
 94, 81, 75, 68, 86, 98, 71, 87, 75, 74, 74]
```

The host TFLite result is output `[-128, 75, -75]`, which selects
`DEGRADING`.
